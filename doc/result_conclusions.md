# 计算结果与验证结论

## 1. 总体结论

本项目已对程序中实现的主要单元完成了较完整的数值验证，包括：

- 收敛性分析；
- 三种分片试验形式的可视化与数值误差汇总；
- 单元验证算例；
- 与 Abaqus 的节点位移对比。

当前覆盖情况见：

```text
cases/report_figures/coverage/figure_coverage_matrix.csv
```

覆盖矩阵显示，Bar、Beam3D2、Plate4、Hex8、BbarHex8 五类单元均已具备收敛性分析、分片试验、Abaqus 位移对比和验证算例图。整体上，程序能够正确完成线弹性静力有限元分析、结果输出和 ParaView 后处理。

## 2. 收敛性分析结论

收敛性分析图位于：

```text
cases/report_figures/convergence/
```

Bar 单元采用正弦分布轴向载荷作为收敛测试工况。随着单元数从 2 增加到 32，端部位移相对解析解的误差由约 `2.15e-1` 降至约 `8.04e-4`，表现出清晰的收敛趋势。

Beam3D2 单元采用悬臂梁均布等效节点载荷工况。随着梁单元数量增加，端部竖向位移逐渐接近解析参考解，相对误差从约 `3.33e-1` 降至约 `1.30e-3`。这说明 Beam3D2 单元在弯曲主导问题中具有合理的网格收敛性。

Plate4 单元采用悬臂板重力载荷序列，网格从 `1x1`、`2x2`、`4x4` 扩展到 `8x8`。以 `8x8` 结果作为参考，误差随网格加密逐步下降，说明 Plate4 单元结果具有自收敛特征。

Hex8 与 BbarHex8 单元采用悬臂实体模型进行自收敛分析。两者均随网格加密表现出位移结果趋近的趋势。BbarHex8 在近不可压缩算例中用于改善体积锁定问题，其收敛趋势和 Abaqus 对比结果均支持该处理的有效性。

## 4. Abaqus 位移对比结论

Abaqus 位移对比图位于：

```text
cases/report_figures/abaqus/
```

整体对比结果如下：

| 算例 | 单元 | 最大绝对位移误差 | 结论 |
| --- | --- | ---: | --- |
| `bar_patch` | Bar | `1.0e-36` | 与 Abaqus 基本一致 |
| `plate4_membrane` | Plate4 | `5.0e-33` | 与 Abaqus 基本一致 |
| `bbarhex8_locking` | BbarHex8 | `3.8e-08` | 与 Abaqus C3D8H 高度一致 |
| `beam_cantilever` | Beam3D2 | `1.54e-05` | 趋势一致，存在截面/方向约定差异 |
| `hex8_patch` | Hex8 | `1.10e-04` | 绝对误差可接受，相对误差受近零分量影响 |
| `mixed_beam_plate_hex` | 混合单元 | `1.59e-02` | 可验证混合单元和 MPC 功能，仍有单元公式差异 |

Bar、Plate4 和 BbarHex8 与 Abaqus 的位移结果非常接近，说明对应单元实现和边界条件处理可靠。

Beam3D2 与 Abaqus B31 的位移趋势和数量级一致，但存在约定差异，主要可能来自梁截面、局部方向和 Abaqus 一般梁截面定义与程序内部梁单元公式之间的不完全一致。

Hex8 算例中最大相对误差偏大，主要是由于部分 Abaqus 参考位移分量接近零，导致相对误差被放大。该算例更应关注最大绝对误差、位移分布趋势和应力状态。

混合单元算例同时包含 Beam3D2、Plate4、Hex8 以及 MPC 约束。该算例的主要意义是验证程序能够在同一模型中装配不同单元组并处理多点约束。其与 Abaqus 的剩余差异主要来自梁、板、实体单元公式和截面约定差异，不宜作为单一单元精度的主要判断依据。

## 5. 验证算例结论

验证算例位移图位于：

```text
cases/report_figures/validation/
```

验证算例显示，各单元在基本边界条件和典型载荷下均能输出合理的位移响应。Bar 单元能准确给出轴向拉压位移；Beam3D2 能表现悬臂梁弯曲变形；Plate4 能给出板膜/板弯曲响应；Hex8 和 BbarHex8 能完成三维实体位移计算；混合算例进一步验证了不同单元组共同装配和求解的能力。

## 6. 需要在报告中说明的事项

结果总体可以支撑报告结论，但写作时应注意以下几点：

- Bar 和 Beam3D2 的新收敛工况已经换成分布载荷问题，适合展示误差随离散加密下降。
- Hex8、BbarHex8 和 Plate4 的部分收敛结果属于以最细网格为参考的自收敛分析，应在报告中明确说明。
- Abaqus 对比中应优先使用最大绝对位移误差和位移趋势进行评价，不应单独强调近零分量导致的相对误差。
- 混合模型适合作为功能验证和 MPC 约束验证，不应作为单一单元精度的主要依据。

## 7. 最终评价

综合收敛性分析、分片试验、验证算例和 Abaqus 位移对比结果，可以认为当前程序的主要单元实现是有效的。Bar、Plate4 和 BbarHex8 的结果与 Abaqus 符合较好；Beam3D2 和 Hex8 的结果在趋势和数量级上合理，差异可以通过截面约定、单元公式和相对误差放大进行解释。混合单元算例证明程序具备多单元组装配、MPC 约束处理和 ParaView 输出能力。

因此，当前结果已经可以作为课程设计报告中的主要数值验证依据。
